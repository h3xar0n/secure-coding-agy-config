# Security Threat Model Skill

## Overview
Use this skill at the start of a security review or component planning to map entry points, trust boundaries, and sensitive data paths.

## Steps
1. **Identify Purpose**: Understand what the component does.
2. **Map Entry Points**: Document all inputs (HTTP endpoints, CLI flags, environment variables).
3. **Identify Trust Boundaries**: Map authentication barriers.
4. **Map Sensitive Data Paths**: Trace where secrets or keys flow.
